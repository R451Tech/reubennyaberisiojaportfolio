Case Study · 05

CheckME Pharmacy POS

A pharmacy point-of-sale system built around Kenyan tax and payments compliance — from KRA ETIMS e-invoicing to M-Pesa.

Category: Retail & POS Role: Full-Stack Developer Year: Live product Status: Live
View live →

01 /Problem

Pharmacies need every sale fast at the counter, compliant with KRA e-invoicing and reconcilable at shift close — three requirements that usually pull a POS in different directions.

02 /What was built

  • Built a receipt engine with sequential invoice numbers and a dual-purpose KRA QR code.
  • Supported A4 PDF and 58/80mm thermal receipt formats from the same data.
  • Added a live, Socket.IO-driven shift-report view.
  • Hardened the application layer with security best practices.

03 /Stack used

ReactNode.jsSocket.IOM-PesaKRA ETIMS

04 /Outcome

A POS where compliance, speed and accountability run through one consistent invoicing engine, with real-time shift reporting.
